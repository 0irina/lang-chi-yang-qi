# 狼吃羊棋 · 96 亿局面破解引擎

狼吃羊棋(5×5 棋盘、3 狼 15 羊)的**完整破解**:全部约 96.4 亿个局面通过逆向求解
(retrograde analysis,Gasser 破解九子棋同款算法)算出**胜负与到终局精确距离**。
AI 在破解表覆盖范围内严格最优;和棋局面(表值=和棋)下,双方各自的"实战偏好"
策略经过统计研究与人类高手实战棋谱的迭代打磨(见 `策略改造方案.txt`)。

- 语言:Python 3(运行时仅需 `numpy`;重新求解需要 `numba`)
- 界面:Tkinter(`solver/gui.py`),无需第三方 GUI 库
- 许可:MIT

---

## 规则(用户确认版)

- 5×5 棋盘,狼 3 只(顶行中间),羊 15 只,狼先手,轮流上下左右走一格;
- 狼可隔 1 个空格跳 2 格吃羊(被吃羊出局);
- **羊剩 3 只 = 狼胜**;狼无路可走 = 羊胜;羊无路可走 = 狼胜;
- 和棋局面按比赛规则**和棋判狼胜**(到限步或重复判和时狼胜);
- 重复规则不对称:狼可以重复不变招,**羊必须变招**(羊直接走回已出现
  局面按和棋=羊输处理,引擎禁止)。

## AI 策略摘要(完整说明见 `策略改造方案.txt` 与两份《使用说明.txt》里的【和棋策略说明】)

引擎**绝不牺牲结果正确性**:表值是胜负就必胜/最顽强抵抗,只在和棋档内
"选哪一步和棋"。

- **狼方**:长线吃子潜力最大 → 走回历史(狼可重复) → 重复压迫(逼羊变招)
  → 先吃 → 骗招度高;
- **羊方**:避重复陷阱 → **高压走廊开局书**(深紫=狼唯一正招;浅紫次选
  =狼正招≤2,深度≥120手) → 不送子(软诱饵) → **狼正招极少**(中局精度
  压力:93% 的中局局面羊能把狼压到唯一正招) → 狼吃不到 → 强手模型评分
  → 败招多 → 显眼败招 → 毒羊;
- 开局书数据:209 条严格走廊线(狼连续唯一正招,最长 22 手)、188 个主选
  局面 + 56 个次选局面,全部经全破解表校验(狼走错任何一步=羊胜);
- 全部走法用 96 亿局面表逐手校验,另有 8 套回归测试。

## 目录结构

```
├─ solver/            全部源码与测试(核心:rules / index / endgame* / engine / gui)
│  ├─ opening_book.py     高压走廊开局书(主选:狼唯一正招)
│  ├─ opening_book2.py    次选高压线(狼正招≤2,120手线)
│  ├─ corridor_search.py  走廊开局全搜索
│  ├─ corridor_search_relax.py / dfs_probe.py   宽松压力搜索/深度探针
│  ├─ endgame_full.py     全局面破解器(断点续跑)
│  └─ tt/                 【不进仓库】数据表目录,见下
├─ 策略改造方案.txt    策略研究与数据结论全记录(含人类实战棋谱逐手核对)
├─ 三角阵研究.txt      中心阵专题研究
└─ WolfSheepAI.spec    PyInstaller 打包配置(可选)
```

## 快速开始

```bash
# 1. 环境
pip install numpy          # 只玩游戏/查询表;若重新求解再加 numba

# 2. 数据表:任选其一
#    a) 自己算(需要 numba;约数小时~10小时,磁盘约 100GB,断点续跑):
python solver/endgame_full.py 15
#    b) 从发布渠道下载,把下面三个文件放进 solver/tt/ :
#       tt/full_packed.npy    (9.0 GB  胜负表)
#       tt/full_dist.dat      (18.0 GB 精确距离表,可选)
#       tt/full_done.flag     (0 字节  标记"使用全破解表")

# 3. 运行
python solver/gui.py
```

> 只有 `full_packed.npy` + `full_done.flag` 也能玩(胜负全知,只是必胜时
> 可能多绕几步、不显示"距终局N步");再加 `full_dist.dat` 即获得最快杀棋
> 与精确距离显示。

## 破解算法一句话

终局种子入队 → 逆向传播:狼方节点"存在一个狼胜后继即狼胜"、羊方节点
"所有后继狼胜才狼胜"(对称处理羊胜);队列耗尽仍未定者=和棋。全部层
(k=3..15)放进同一索引空间一起求不动点(吃子跨层传播)。
