# 狼吃羊棋 破解项目

规则(用户确认版):5×5 棋盘,3 狼 15 羊,狼先手,轮流上下左右走一格;
狼隔 1 空格跳 2 格吃羊;羊剩 3 只狼胜;狼无路可走羊胜;羊无路可走狼胜;
循环局面判和(实际对局按"重复回避"走次优变招)。

## 文件说明

| 文件 | 作用 |
|---|---|
| `rules.py` | 权威规则:位棋盘走法生成、终局判定 |
| `index.py` | 组合数编解码(C(25,3) 狼位 × C(22,k) 羊位)+ 镜像压缩表 |
| `endgame.py` | 残局逆向求解器(全空间,已验证 k=3..5,0 错误)+ 查询接口 |
| `endgame_full.py` | **全局面破解器**(镜像压缩 95.9 亿状态 + 2bit/6bit 打包 + 磁盘队列,支持断点续跑) |
| `engine.py` | 对弈引擎:破解表查询 + 和棋实战偏好(高压走廊开局书/中局精度压力等) |
| `gui.py` | 图形界面:人机对弈、开局库面板、分析模式、破解线显示 |
| `winrate.py` | 人类失误模型(和棋局面评分/预估胜率) |
| `opening_book.py` | 高压走廊开局书·主选(羊走后狼唯一正招,188局面) |
| `opening_book2.py` | 高压走廊开局书·次选(狼正招≤2,120手线,56局面) |
| `corridor_search.py` | 严格走廊开局全搜索(209线) |
| `corridor_search_relax.py` / `dfs_probe.py` | 宽松压力搜索 / 深度探针 |
| `tests.py` / `selftest.py` | 规则/索引/残局表单元测试 / 引擎冒烟测试 |
| `tt/` | 表文件(不进仓库):`full_packed.npy`(全破解表)、`full_dist.dat`(距离表)、`full_done.flag` |

## 使用方法

```bash
# 运行 GUI(自动加载已有破解表)
python solver/gui.py

# 单元测试
python solver/tests.py 5

# 全局面破解(默认 k=3..15,约 10 小时,断点续跑)
python solver/endgame_full.py 15
python solver/endgame_full.py 15 --resume
```

## 破解规模

- 全状态空间:2300 狼位 × 4,083,994 羊位 × 2 回合 ≈ 188 亿
- 镜像压缩后:约 95.9 亿状态,每状态 1 字节(2bit 胜负 + 6bit 计数器)
- 内存表约 9.6GB,队列与距离表放磁盘 memmap(约 96GB)
- 求解算法:终局种子 + 逆向传播(Gasser 九子棋法),胜负 + 和棋 + 到终局距离

## 已完成验证

- k=3..5 全空间表:独立复核 0 错误;30 万随机局面与镜像压缩表交叉验证 0 不一致
- 距离表:同验证(最大距离 125)
